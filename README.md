# RPCS3 ドラゴンクエストヒーローズ 日本版 VRAMパッチ

『ドラゴンクエストヒーローズ 闇竜と世界樹の城』の日本版で発生する、RSXの `Access violation reading location 0xcf900000 (unmapped memory)` の回避・軽減を目的とする実験的なゲームパッチです。

ゲームが利用するローカルVRAMの確保用プールを少し小さくし、マップされたVRAMの末尾に約1MiBの余裕を残します。エフェクトや描画処理の省略は行いません。

## 対象

- ゲーム：ドラゴンクエストヒーローズ 闇竜と世界樹の城
- シリアル：`BLJM61256`
- ゲームバージョン：`01.06`
- PPUハッシュ：`PPU-9b21703c61db8e696720af34485921f5f7078b2a`
- パッチバージョン：`3.0`

異なるバージョンやハッシュには対応していません。

## 導入

1. RPCS3を終了します。
2. `BLJM61256_patch.yml` をRPCS3の `patches` フォルダーに配置します。同名ファイルがある場合は事前にバックアップしてください。
3. RPCS3を起動し、ゲームを右クリック → **Manage Game Patches** を開きます。
4. **Experimental - Reserve 1 MiB at local VRAM pool end** を有効にして **Save** します。
5. ゲームを通常起動し、ゲーム内のセーブデータから再開します。

**パッチ適用前のステートセーブを読み込まないでください。** メモリープールの初期化時に作用するため、古いステートでは変更前のメモリー配置が復元されます。通常のゲーム内セーブデータとステートセーブは別です。

同じゲーム用のメモリー確保・描画変更パッチとの併用は未検証です。このパッチだけで動作確認してください。

## 変更内容

| PPUアドレス | 変更前 | 変更後 |
| --- | --- | --- |
| `0x005fc210` | `0x30c6fe00` — `addic r6,r6,-0x200` | `0x3cc6fff0` — `addis r6,r6,-0x10` |

`cellGcmGetConfiguration` から取得した `localSize` を、ゲーム内のメモリープール初期化へ渡す前の1命令を変更します。

- 変更前のプール上限：`min(要求サイズ - 512, localSize - 512)`
- 変更後のプール上限：`min(要求サイズ - 512, localSize - 1048576)`

`localSize = 0x0f900000` の場合、上限は `0x0f8ffe00` から `0x0f800000` へ下がります。実際のVRAMマッピング容量やRPCS3の例外処理は変更しません。ゲーム実行ファイルを直接上書きせず、RPCS3が起動時にメモリー上へ適用します。

## 確認できた範囲と制限

RPCS3 `0.0.43-20336` で1命令の適用を確認し、以前フリーズしていた箇所を通過できたというプレイ結果があります。ただし、同条件での厳密なON/OFF比較や、長時間・全場面での安定性は未確認です。根本原因やすべてのクラッシュの解消を保証するものではありません。

使用可能なメモリープールが少し減るため、別の場面で確保失敗や表示・進行への影響が出る可能性があります。不具合が出た場合はパッチを無効にしてください。

## 解除

ゲームを停止し、**Manage Game Patches** で本パッチのチェックを外して **Save** した後、ゲームを通常起動します。

- `README.md`：導入方法と変更内容
